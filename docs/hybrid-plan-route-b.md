## 0. 一页摘要

| 项目 | 内容 |
|---|---|
| 音素 | 本地 wav2vec2＋GOP 引擎（v2 方案），录音不出本机 |
| 重音、语调、意群停顿 | 阿里云「智能科教内容生成」儿童句子评测 `en.sent_kid.score`，单词用 `en.word_kid.score` |
| 隐私 | **调用阿里云时录音会上传**。因此设计成可开关、按题目类型调用，而不是每次都上传（第 4 节） |
| 费用 | 阿里云按次计费，约 0.004 元/次；每天练 15 分钟，每月约几元人民币（第 12 节） |
| 最大的未知数 | 阿里云的重音和语调结果对你女儿准不准、接入协议和账号地区限制。所以第一步是「技术验证＋小规模标准答案集测试」（里程碑 0 和 8） |
| 好处 | 阿里云这条线可以先上线，不用等本地引擎做完，孩子很快就能练重音和语调 |

## 1. 分工：谁负责评什么

| 评测维度 | 负责方 | 依据 | 粒度 |
|---|---|---|---|
| 音素对错、漏音 | **本地引擎** | GOP＋置信度（v2 第 4–5 节） | 每个音素 |
| 单词重音 | **阿里云** | `stressref`（是否要求重读）、`stressscore`（0/1，实际是否符合） | 每个单词，二值 |
| 句末语调（升 / 降） | **阿里云** | `toneref`（1＝升调，0＝降调）、`tonescore`（0/1） | 每个标注了语调的位置，二值 |
| 意群停顿 | **阿里云** | `senseref`、`sensescore`（0/1） | 每个标注位置，二值 |
| 连读（可选） | **阿里云** | `liaisonref`、`liaisonscore`（0/1） | 每个标注位置，二值 |
| 多音节单词的音节重音 | **阿里云** | 儿童单词评测 `en.word_kid.score` 的 `stress` 数组 | 每个音节 |
| 漏读、重复读 | 两边都有 | 阿里云 `dp_type`；本地删除证据 | 单词 |
| 阿里云自己的音素分 | **只用于评测对比，不展示**（待你决定，第 15 节） | `phone[].score`、`pherr` | 音素 |

**注意：** 阿里云给的重音和语调结果是「对 / 不对」的二值判断，不是细致的连续分数。对 8 岁孩子来说这反而合适，但它无法告诉你「差多少」。

## 2. 必须先知道的限制

1. **录音会离开本机。** 只要调用阿里云，录音就会上传。阿里云文档的返回示例里，录音下载地址的域名（`files.cloud.ssapi.cn`）不是 aliyun.com，说明可能由合作方处理。开通前要看清数据保存和处理条款。
2. **部分字段目前是「预留」。** 儿童句子评测文档里，句子级的 `rhythm.stress`、`rhythm.tone`、`rhythm.sense` 都标为「预留，暂未使用」，只有 `rhythm.overall` 和单词级的 `stressscore`、`tonescore`、`sensescore` 可以用。**必须在里程碑 0 实测这些字段是否真的有值。**
3. **重音和语调的期望值可能要自己标注。** 文档提到 `refText` 里需要用「文本符号」来标注期望的重音、语调、意群和连读，具体写法在另一份文档里。如果不标注，可能得不到这些评测结果。**要在里程碑 0 确认。**
4. **接入协议没写清楚。** 儿童句子评测文档没有说明用什么协议或 SDK，返回示例里有 `connect`、`sig` 签名字段，看起来是 SDK 或 WebSocket 方式。需要从控制台或 SDK 包里确认。
5. **文档有矛盾之处。** 比如 `accent` 文档写的是 `"en"`/`"am"`，示例里却是数字 `1`；适用年龄一处写 12 岁以下，另一处写 10 岁以下。一切以实测为准。
6. **账号和地区。** 产品介绍写的是「面向中国 3–18 岁学生」。你在新加坡，可能需要中国站账号和实名认证，**这是里程碑 0 第一件要确认的事**，否则方案要换供应商（SpeechSuper 或 Speechace）。
7. **准确度未验证。** 厂商宣传不等于对你女儿准，要靠第 11 节的标准答案集验证。

## 3. 整体架构

```
浏览器 (static/app.js)
  │  录音 + 题目 id
  ▼
server.py  POST /api/assess
  │
  ├──► 本地音素引擎 (始终运行，离线) ───────────────┐
  │                                                 │
  └──► 阿里云客户端 (仅当：混合模式开启            │
        且题目需要重音/语调评测)                    │
        ── 超时 / 失败 → 跳过，不影响音素结果 ──────┤
                                                    ▼
                                         合并器 (第 7 节)
                                                    ▼
                                         统一 JSON (第 8 节)
                                                    ▼
                                    app.js 展示 (第 9 节)
```

- 两路**并行**调用，总耗时取较慢的一路。
- 阿里云失败不影响音素反馈，界面显示「重音 / 语调这次没评上」。
- 题目的参考文本和期望标注都存在服务器的题库里，前端只传题目 id。

## 4. 隐私设计

| 措施 | 做法 |
|---|---|
| 三种模式，家长在设置里切换 | **仅本地**（不上传）／**按需混合**（默认：只有重音、语调类题目上传）／**全部混合** |
| 不让对方保留下载地址 | 请求固定 `attachAudioUrl = 0` |
| 只传必要内容 | 只上传单句音频，不传姓名、年龄等个人信息；题目文本是公开教材句子 |
| 本地不留存 | 服务器不保存上传过的音频；日志只记分数和题目 id |
| 透明 | 界面上标出本题是否会上传（例如显示一个小云朵图标） |
| 开通前检查 | 阅读阿里云及其合作方的数据处理、保存期限条款；不满意就退回「仅本地」模式或换供应商 |

## 5. 阿里云接入

### 5.1 里程碑 0：技术验证（先做，花时间最少）

需要回答以下问题，**全部有答案后再写正式代码**：

| # | 问题 | 怎么确认 |
|---|---|---|
| 1 | 新加坡能否开通，需不需要中国站实名 | 注册、开通试用 |
| 2 | 接入方式（SDK / WebSocket / HTTP）、鉴权方式（appKey＋签名） | 控制台、SDK 包、技术支持 |
| 3 | 支持的音频格式（文档示例：16 kHz、单声道、16 bit、ogg） | 实测 wav、ogg |
| 4 | `refText` 里重音、语调、意群的标注写法 | 查「文本符号」文档，做实验 |
| 5 | `stressscore`、`tonescore`、`sensescore` 及 `rhythm.*` 是否真的有值 | 用 10 条录音实测 |
| 6 | 从新加坡调用的延迟 | 实测 |
| 7 | `accent`、`typeThres`（严格程度）、`phdet`、`outputPhones` 的实际效果 | 实测 |
| 8 | 实际价格 | 控制台计费页 |

**输出：** 一份验证记录，以及一个能跑通的最小 Python 脚本。

### 5.2 请求参数（初定，验证后调整）

| 参数 | 值 | 说明 |
|---|---|---|
| `coreType` | `en.sent_kid.score`（句子）或 `en.word_kid.score`（单词） | 儿童专用 |
| `refText` | 带重音、语调、意群标注的句子 | 写法见里程碑 0 第 4 项 |
| `accent` | `"en"` 或 `"am"` | 和本地引擎的 locale 一致 |
| `typeThres` | 2（宽松），再根据实测调整 | 文档说明：1 严格，2 宽松，3 很严，4 很松 |
| `attachAudioUrl` | 0 | 隐私 |
| `outputPhones`、`phdet` | 1 | 拿阿里云的音素结果用于评测对比 |

### 5.3 客户端模块 `aliyun_client.py`

- 封装鉴权、请求和超时（建议 5 秒）、重试（最多 1 次）。
- 把阿里云原始返回**原样保存在内存里**，交给合并器；调试模式下可写入本地文件，便于排查。
- 密钥放在本地环境变量或配置文件里，**不进前端，不进代码仓库**。

## 6. 练习内容设计

重音和语调评测只对**有明确目标**的句子才有意义，所以题库里每题要带元数据：

```json
{
  "id": "q-012",
  "text": "Do you like bananas?",
  "focus": ["phoneme", "intonation", "stress"],
  "aliyun_ref_text": "<带标注的版本，写法待里程碑 0 确认>",
  "expected": {
    "final_intonation": "rise",
    "stressed_words": ["like", "bananas"],
    "syllable_stress": { "bananas": 2 }
  },
  "level": "short-sentences"
}
```

**题目类型建议**

| 类型 | 例子 | 练什么 |
|---|---|---|
| 一般疑问句 | *Do you like cats?* | 句末升调 |
| 陈述句 | *I like cats.* | 句末降调 |
| 特殊疑问句 | *Where is my bag?* | 句末降调（孩子常误用升调） |
| 多音节单词 | *banana, elephant, computer, tomorrow* | 单词内音节重音 |
| 对比重音 | *I like **red** apples, not green ones.* | 句中重读 |
| 只练音素 | *Three thin thumbs.* | 不上传，纯本地 |

题目标记了 `focus: ["phoneme"]` 时，按需混合模式下**不会上传**。

## 7. 结果合并规则

### 7.1 单词对齐
阿里云的 `details[i].char` 要和本地引擎的单词一一对应：
- 统一做规范化：小写、去标点、处理缩写（*don't*、*I'm*）。
- 按顺序做序列对齐，不能只看位置下标，因为两边对漏读、重复读的处理可能不同。
- 对不上的单词，该词的阿里云结果标为 `unmatched`，不展示。

### 7.2 冲突处理

| 情况 | 处理 |
|---|---|
| 阿里云判漏读（`dp_type = 1`），本地认为读了 | 该词标为 `uncertain`，不判错 |
| 本地判漏音，阿里云认为读了 | 音素层面按本地的置信度规则处理；不额外扣分 |
| 某词音素不准**且**重音不对 | 只给一条提示，优先说音素，避免一次批评太多 |
| 阿里云超时 / 失败 | 只展示音素；重音、语调显示「这次没评上」 |
| 阿里云重音、语调字段为空 | 视为「未评测」，不当作错误 |

### 7.3 每次最多几条提示
- 每句最多 **2 条**改进提示：最多 1 条音素和 1 条重音 / 语调。
- 其余问题只记在家长视图里。

## 8. 统一输出格式

```json
{
  "status": "Success",
  "item_id": "q-012",
  "reference_text": "Do you like bananas?",
  "sources": { "phoneme": "local", "prosody": "aliyun" },
  "uploaded": true,
  "phoneme": {
    "AccuracyScore": 82,
    "CompletenessScore": 100,
    "Words": [
      { "Word": "bananas", "AccuracyScore": 74, "status": "ok",
        "Phonemes": [ { "Phoneme": "n", "AccuracyScore": 90, "confidence": "high", "status": "ok" } ] }
    ]
  },
  "prosody": {
    "available": true,
    "rhythm_overall": 75,
    "words": [
      { "Word": "bananas", "stress_expected": true, "stress_ok": true },
      { "Word": "bananas", "position": "sentence_final",
        "intonation_expected": "rise", "intonation_ok": false }
    ],
    "syllable_stress": [
      { "Word": "bananas", "expected_syllable": 2, "ok": true }
    ]
  },
  "feedback": [
    { "type": "intonation", "word": "bananas", "message_key": "question_should_rise" }
  ],
  "raw": { "aliyun": "(仅调试模式)" }
}
```

- `prosody.available = false` 表示没有上传，或者阿里云失败。
- 和 v2 一样，**没有 `DisplayText`**，不展示「系统听到了什么」。

## 9. 孩子看到的反馈

| 情况 | 孩子看到的 |
|---|---|
| 升调对了 | 句末出现一个向上的箭头 ↗ 和一颗星 |
| 疑问句应该升调却降了 | 「这是问句，结尾要像问问题一样往上扬 ↗，听一遍再试！」并播放示范 |
| 重音对了 | 该单词变大一点，打勾 |
| 重音位置不对 | 把单词按音节拆开显示：ba-**NA**-nas，重读音节放大，播放示范 |
| 阿里云没评上 | 不提重音和语调，只显示音素结果 |
| 不确定 | 不评价，最多一句「再读一次吧」 |

示范音频用本地 TTS（Piper）或浏览器自带语音，重读音节用 SSML 加强（如果引擎支持）。

## 11. 评测：怎么知道准不准

### 11.1 标准答案集（混合方案最重要的一步）
- **录音：** 你女儿 100–200 句，覆盖第 6 节所有题目类型；如果可以，再加 1–2 个同龄孩子。
- **标注人：** 一位英语老师（最好两位，用来算老师之间的一致率）。
- **标注内容：**

| 维度 | 标注方式 |
|---|---|
| 音素 | 每个音素：对 / 错 / 漏，错的话写读成了什么 |
| 单词重音 | 每个多音节词：重音位置对 / 错 |
| 句中重读 | 标注了重读的词：重读了 / 没有 |
| 句末语调 | 升 / 降 / 平，对 / 错 |

### 11.2 要回答的问题

| 问题 | 指标 |
|---|---|
| 阿里云的重音判断准吗？ | 与老师对比的一致率；**把对的判成错的比例**（孩子最怕被冤枉） |
| 阿里云的语调判断准吗？ | 同上 |
| 本地音素引擎准吗？ | v2 第 8.3 节的指标，在这批儿童录音上重算 |
| 本地和阿里云谁的音素更准？ | 两者分别与老师对比（只用于决策，不展示阿里云音素） |
| 老师之间有多一致？ | 这是机器能达到的上限 |

### 11.3 通过标准（跑测试**之前**定好，见第 15 节）
例如：重音、语调「对的判成错」≤ 10%；不达标的维度就不展示给孩子，只在家长视图里显示。

## 13. 里程碑

两条线可以**并行**：阿里云线较快，可以先让孩子用上。

| # | 线 | 交付 | 完成标准 |
|---|---|---|---|
| **M0** | 阿里云 | 账号开通＋技术验证（第 5.1 节 8 个问题） | 8 个问题都有答案；最小脚本跑通；**若无法开通，改评估 SpeechSuper / Speechace，并更新本方案** |
| M1–M4 | 本地 | v2 方案的里程碑 1–4（音素引擎及评测） | 见 v2 第 11 节 |
| M5 | 阿里云 | `aliyun_client.py`＋题库 `items.json`（带标注） | 题库每题都能拿到有效的重音 / 语调字段 |
| M6 | 合并 | `merge.py`＋统一 JSON | 单词对齐和冲突规则的单元测试通过 |
| M7 | 前端 | `/api/assess` 接入、新展示、隐私设置 | 浏览器端到端可用；`/api/recognize` 不受影响 |
| M8 | 评测 | 标准答案集录音、标注、对比报告 | 按第 11 节出数据 |
| M9 | 决策 | 根据 M8 决定每个维度展示与否、阈值、隐私默认值 | 达到事先约定的标准才对孩子展示 |

**过渡期选项（待你决定）：** 本地引擎通过 M4 之前，是否暂时用阿里云的音素结果给孩子反馈？好处是马上能用，代价是音素题也要上传录音。

## 14. 风险与应对

| 风险 | 应对 |
|---|---|
| 新加坡无法开通阿里云儿童评测 | M0 第一项就确认；备选 SpeechSuper / Speechace，合并器按供应商写适配层 |
| 重音、语调字段实际为空或是预留 | M0 实测；为空就换供应商或只用 `rhythm.overall` |
| 期望标注写法复杂，题库难维护 | 题库集中管理，写一个标注校验脚本 |
| 阿里云判断对孩子不准 | M8 用标准答案集验证；不达标的维度不展示 |
| 两边结果矛盾，孩子困惑 | 第 7 节冲突规则；每句最多 2 条提示 |
| 网络慢或断网 | 超时后只显示本地音素结果 |
| 隐私 | 第 4 节的三种模式、`attachAudioUrl = 0`、按需上传 |
| 供应商改价格或接口 | 客户端隔离在单个模块；原始返回在调试模式下保存，便于对比 |
